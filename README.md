# Epic Store
متجر إلكتروني متكامل، يوفر تجربة تسوق مميزة لكل من البائع والمشتري. يتميز المتجر بنظام صلاحيات منفصل، حيث يمتلك البائع تحكمًا كاملاً في إدارة المنتجات والأسعار.
المتطلبات: يجب تثبيت برنامج XAMPP لتشغيل المشروع وتهيئة بيئة العمل. تم بناء المشروع باستخدام إطار العمل لاراڤل وقاعدة بيانات MySQL.
